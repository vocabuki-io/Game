# バックログ（v0で外した要素・後で1つずつ戻す候補）

v0「3つの鍵」はコアの読み合いだけに絞った。ここに退避した要素は**消していない**（コードは
`git` 履歴とマップメーカー関連ファイルに残る）。v0が面白いと確認できたら、**1つずつ**戻して
都度プレイテストする。足して複雑になりすぎたら戻す。

## 追加のおすすめ順
1. **扉に「位置」と移動**を足す → マップメーカー(`public/editor.js`・`src/engine/mapdef.js`)が復活
2. **霧**（看守は囚人の位置が見えない）
3. **禁制品＋検査リスク**（隠す vs 探す）
4. **イベント**（食事/刑務作業/点呼を看守が強制、違反で独房）
5. **技術札（模範作業で育つ重み付きデッキ）／アイテム**

## 退避した仕様メモ
### マップ／移動／霧
- すごろく風ノードグラフ、座標・部屋・門・隠し通路、囚人=未探索マスは「？」、看守=隠し通路のみ不可視。
- 共有盤面レンダラ `public/board.js` / `board.css`（マップメーカーとゲームで同一描画）。
- `src/engine/mapdef.js`（BUILTIN＋`fromEditor`）、`map.js`、`view.js`の座標配信。

### アクション（旧）
- 囚人：移動/偵察(霧開け)/隠す(隠蔽)/作業(リソース・工具)/掘る(トンネル)。
- 看守：巡回/監視(立入禁止の現行犯)/検査(禁制品の現行犯)/点呼。

### 違反・勝敗（旧／検討中）
- 一発アウト＋追跡フェーズ（逃走/反撃 vs 封鎖/捕縛）。
- 改訂案：違反→独房、独房3回で処刑（3ストライク）。
- 脱出ルート5種から毎試合2種ランダム、タスクシートUI。

### デッキ構築（ブレスト済み・未実装）

  手札に出る重みUP（上限あり）。**アイテム＝使い切り（一部常設）・重複可**、取得で次ターンからプール入り。
- 技術札候補：削岩/合鍵/配管図/縄ばしご/ヤスリ/隠しポケット/すり替え/足音消し/気配察知/変装/
  見取り図/内通者/カメラ細工/賄賂/煙幕/騒動/停電/自作ナイフ/目くらまし/闇ルート/器用さ。

## バランスの指針（忘れないため）
- 奥深さは「ルールの数」ではなく「少ないルールの噛み合い」から出す。
- 追加の物差し：「それを消したら悩ましい選択が減る？」減らないなら入れない。
- 核：模範囚は倒せない（看守は証拠/読み/時間でしか勝てない）。重複で重みを上げる要素は必ず上限を付ける。
